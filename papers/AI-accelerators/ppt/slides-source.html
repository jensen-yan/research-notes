CACHE DID NOT DISAPPEAR

不是不要 cache，而是主战场变了。

EXPLICIT PATH
规则 tensor 主路径

GEMM tile、attention block、conv tile、weight / activation / partial sum，适合 HBM -> SMEM/VMEM/scratchpad -> tensor core。

CACHE PATH
不规则和系统路径

metadata、gather/scatter、CPU 控制流、KV cache 动态管理、跨 kernel 复用、runtime 和系统软件仍然需要 cache。

局部性没有消失，只是从 cache-line 粒度提升到 tensor / kernel / stream 粒度。

AME · OWNERSHIP
30 / 34
WHO OWNS THE TENSOR?

AME 的核心问题：谁拥有这块 tensor？

A AME LOCAL PATH
HBM -> SPM -> CUTE
适合大 GEMM、prefill、规则 tile，不希望 CPU 反复触碰。
  • 更容易做 dataflow
  • 需要 DMA / fence / ownership
  • 一致性边界更显式
B SHARED L2 PATH
HBM -> L2 -> CPU + AME
适合动态控制、小 batch、norm、softmax、metadata 和 CPU 协同。
  • 生态和控制更自然
  • 可能反复穿越 L2
  • matrix/vector 边界要量化
切换 ownership 的成本，可能就是 AME 软件栈要回答的问题。

Data movement is the architecture.

Compiler/runtime is part of the machine.

XSAI/AME should evolve by evidence.
