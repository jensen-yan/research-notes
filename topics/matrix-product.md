对于一维向量来说
a = [1,2,3], b = [4,5,6]
1. 内积：c = a * b = 1 * 4 + 2 * 5 + 3 * 6 = 32, 结果是标量
2. 外积：c = 一个矩阵
3. ```
   a b^T =
[
  [1×4, 1×5, 1×6],
  [2×4, 2×5, 2×6],
  [3×4, 3×5, 3×6]
]
=
[
  [4, 5, 6],
  [8, 10, 12],
  [12, 15, 18]
]
   ```  
4. 内积长用于计算相似度，表示两个向量在同一个方向的重合程度有多高，基本和点积等价
5. 外积：把每个元素都配对一下

对于矩阵乘法：既可以看做内积，也可以看做外积
1. 传统视角：每个元素就是一个内积，C_ij = A  i 行 内积 B j 列
2. 外积视角：按k 每次生成一个矩阵，然后累加
